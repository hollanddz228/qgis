ЛАБОРАТОРНЫЕ РАБОТЫ 5 И 6 — QGIS

1. Полностью распакуйте архив. Не открывайте проекты прямо из ZIP.
2. Откройте index.html обычным браузером: там порядок работ, пояснения и карты.
3. Для лабораторной 5 откройте в QGIS файл Lab5/Lab_5.qgz.
4. Для лабораторной 6 последовательно откройте проекты из папки Lab6.

Вторая ссылка задания ведёт на весь модуль, поэтому работа 6 состоит
из четырёх уроков. Для урока о проекциях сохранены три отдельных проекта.

Папки data, Lab5 и Lab6 переносите вместе: в проектах относительные пути.
Все используемые данные включены, интернет для открытия карт не нужен.
Слой solution — итог подбора зданий. Серые здания оставлены для сравнения.
Промежуточные результаты доступны в GeoPackage и в списке слоёв проектов.

Чтобы увидеть линии в работе 5: правой кнопкой по routes → Приблизить к слою.
Чтобы увидеть достижимость в работе 6.3: выключите слои маршрутов,
включите service_area_250m и network_points.
В работе 6.4 для сравнения интерполяций переключайте слои IDW,
отключив исходный SRTM. Откройте таблицы слоёв для просмотра расчётов.

Результаты построены средствами PyQGIS и GDAL по руководству QGIS 3.44.
Проверка выполнена в QGIS 3.40.6 на Linux, включая перенос в другую папку.
Открытие в вашей конкретной установке QGIS 3.44.14 на Windows ещё не проверялось.
Исходные присланные проекты не изменены. Управление вашим ПК не использовалось.
